# npie

Bring-up and test engineer for boards designed with hwde: generates a staged,
design-derived bring-up procedure, runs it through one instrument driver layer
with human-confirmed steps, and records each run with a report.

Entry point: [SKILL.md](SKILL.md). Design: [reference/design.md](reference/design.md).
Tests: `tests/` in the repo root, against a simulated bench only.
